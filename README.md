# OpenUML — 受 StarUML 启发的在线 UML 建模工具

一个用**纯原生 JavaScript + SVG**（零依赖、免构建）实现的 UML 建模工具，
布局与交互方式参考了经典桌面建模工具 StarUML 7 的使用体验。

本项目是在 REA（reverse-engineer-anything）工作流指导下，
对本机安装的 StarUML 7.1.1（Electron 应用）做静态逆向分析后，
依据分析到的界面结构与交互模型**从头独立实现**的复刻版本——没有复制任何 StarUML 源码或资源。

## 运行

任意静态文件服务器即可，例如：

```bash
python3 serve.py 8642
# 打开 http://127.0.0.1:8642/
```

## 样例与 StarUML 转换

`samples/staruml/UMLExample.ouml` 由 StarUML 官方样例仓库的
`UMLExample.mdj` 转换而来（MIT，版权归 MKLabs），包含 28 张图、
覆盖全部 15 种 UML 图类型、719 个模型元素；转换报告见同目录
`UMLExample.report.json`。

使用离线转换器重新生成：

```bash
python3 tools/mdj_to_ouml.py input.mdj output.ouml --report report.json
```

转换器只映射 OpenUML 已实现的 UML 视图；活动图引脚、结构化活动节点、
正交区域等缺失记号会被跳过并写入报告。样例仓库中的 BPMN / ERD / C4 /
SysML 等非 UML 扩展样例不在映射范围内。

## 功能

### 图表与图元
- **类图**：类、接口（«interface»）、枚举、数据类型、原始类型（«primitive»）、
  信号（«signal»）、包、注释、**框架 Frame**（带名称页签，可容纳子元素）、
  **模板参数**（右上角虚线隔间，`T` / `K : Type`）、**模板绑定**（«bind» 虚线）、
  **实现**（Realization）、**N 元关联**（菱形节点，多条关联边共享同一关联模型）、
  **关联类**（点击关联创建，虚线连接到关联）、
  **约束**（`{specification}` 注释形图元）、
  **标记值**（`{tag=value}`，显示在类名与属性/操作签名上）；
  构造型**六种显示模式**（无/标签/装饰/装饰+标签/图标/图标+标签，含 24×24 装饰图标、
  图标形态占位与 X 交叉占位图标，对应 StarUML UMLStereotypeDisplayKind）；
  标记值以 `{tag=value}` Property 行显示（可关闭）；
  属性面板提供**显示开关**：构造型显示、可见性、类型、操作签名、属性多重性、
  **自动换行**（名称/成员/枚举字面量）、命名空间 `(from …)`、
  抑制属性/操作/字面量隔间；
  应用构造型后其属性自动出现在属性面板并可写入标记值
- **用例图**：参与者（Actor）、用例（UseCase）、系统边界（Subject）、include/extend
- **序列图**：生命线（Lifeline）、同步消息（实心箭头）、异步消息（开放箭头）、
  回复消息（虚线）、**创建消息**（«create» 虚线、目标生命线自动定位）、
  **删除消息**（«destroy» + 终止 X 标记）、**发现/丢失消息**（端点实心圆点）、
  自消息（回环）、**自动激活条（Activation Bar）**、
  **组合片段**（alt/opt/loop/par/break/critical/neg/assert/ignore/consider，
  五边形 operator 页签、多操作数与守卫条件、可增删操作数、
  **操作数分隔线可拖拽**、**片段可嵌套**）、
  **交互引用（ref）** 图元
- **状态机图**：状态（圆角框）、初始/终止状态、选择（菱形）、连接点（实心菱形）、
  浅/深历史（H / H*）、迁移、自迁移（右侧回环）、**复合状态（内嵌子状态）**、
  **正交状态与区域**（一键创建两个区域，区域可嵌套状态）、**子机状态**、
  **入口点 / 出口点 / 终止节点 / 连接点引用**（贴附状态边缘）
- **活动图**：动作、初始节点、活动终点、流终点（⊗）、判定/合并（菱形）、
  分叉/汇合（实心横条）、控制流（守卫条件标签）、
  **对象节点/对象流/发送信号/接收信号**、**泳道（垂直/水平分区）**、
  **输入/输出引脚**（贴附动作并随其移动）、**结构化活动节点**与**中断区域**（容器）、
  **中心缓冲/数据存储/活动参数节点**、**接收时间事件**
- **组件图**：组件（左缘双凸tab）、构件（折角文档）、接口、依赖、组件实现；
  **提供接口**（棒棒糖）与**需求接口**（插座）独立图元
- **部署图**：节点（3D 立方体，**可嵌套节点/构件/实例**，随容器移动与释放）、
  构件、部署关系（«deploy» 虚线）、通信路径
- **包图**：包、子系统（带组件角标）、模型、包含关系（⊕ 圆圈加号端）；
  包/模型/子系统作为容器，拖入自动归属、移动随动、删除释放，
  并按包体边界裁剪子元素（嵌套包取边界交集，导出 SVG 保留裁剪）；
  **容器缩放联动子元素**（西/北随动、东/南推挤回框内，可撤销）
- **通信图**：对象（下划线名）、链接、**自链接**、**序号消息叠加**
  （`1: → 下单(items)`，双击链接逐条编辑文本与正向/反向），
  消息工具自动追加到已有链接
- **对象图**：对象/构件实例/组件实例/节点实例（`name : Classifier` 下划线记法，
  名称自动适配宽度）、**槽（Slots）**（`name = value` 分隔区，可增删编辑）、
  链接、定向链接（可编辑端角色名/多重性）、
  **链接对象 LinkObject**（独立连接线 + 中点完整对象框：`名 : 类` 下划线与槽行，
  挂真实 UMLObject 模型，属性面板编辑分类器与槽，undo/redo 一致）
- **复合结构图**：协作（虚线椭圆）、部件（圆角框，共享/组合两种线型）、
  **端口**（贴在类/接口/组件/协作边缘的小方块，随容器移动并自动吸附，
  支持 `~` 共轭标记）、连接线（**装配 ball & socket / 委托虚线箭头**）、
  协作使用（`name: 协作类型`）、角色绑定（带 role 标签的虚线箭头）、实现；
  部件与端口拖入类/组件/协作后自动归属，移动或删除容器时随动/释放
- **信息流图**：信息项（`«information»` 类框，含属性与操作）、
  信息流（`«flow»` 点线，方向单向/双向/无、conveyed 信息项标签、
  realizing 连接线/活动边/消息关联），支持在属性面板维护 **conveyed 信息项列表**
  并显示在连线标签上
- **Profile 图**：元类（`«metaClass»`）、构造型（`«stereotype»`，可编辑属性/操作）、
  枚举、扩展（实心箭头指向元类，可设置多重性）、泛化；`«profile»` 包标记
- **交互概览图**：交互引用（ref 框）与内联交互**双击打开可编辑序列图**
  （自动创建同名图表）、**Gate**（frame 边缘信息出入口）、
  初始/终止/分叉/汇合/合并/判定节点与带守卫的控制流
- **Timing 时序图**：水平生命线、状态/条件带（相邻状态自动绘制阶梯切换线）、
  时间段、时间刻度、时间约束、持续时间约束（括号）、垂直消息（可连接生命线或状态带）
- **关系**：关联、定向关联、聚合（空心菱形）、组合（实心菱形）、依赖（虚线）、
  泛化（空心三角）、接口实现（虚线+空心三角）、包含/扩展（«include»/«extend»）、注释连接
- **注记图元**：文本、矩形、椭圆（纯视图元素，样式可调）、约束（`{spec}` 注释形）
- **容器包含**：泳道、复合状态与框架 Frame 是真正的容器——拖入其中的元素自动归属，
  拖动容器时子元素整体随动，移出即脱离；删除容器会释放子元素（全程可撤销）
- **自动适应高度**：类/接口/枚举框随成员数量自动增高、删除成员后回收多余高度；
  自动尺寸是派生布局（不写入撤销栈、不弄脏工程），手动调整的尺寸作为下限保留
- **图表外框**：按 StarUML 惯例自动绘制，左上角页签携带 UML 类型前缀
  （cd / uc / sd / stm / ad / cp / dp / pkg / comm / od / cs / tm / iod / if / pf）与图表名

### 交互（对标 StarUML）
- 左侧：图表列表（按类型图标区分）+ 工具箱（常用 / 类图 / 用例图 / 序列图 /
  状态机图 / 活动图 / 组件图 / 部署图 / 包图 / 通信图 / 对象图 / 复合结构图 /
  信息流图 / Profile 图 / 交互概览图 / Timing 时序图 可折叠分组，全部平铺，SVG 图标）
- 右侧：模型资源管理器（树，自动展开、右键菜单）+ 属性 / 样式面板
- **快速查找（Ctrl+F）**：按名称搜索图表与模型元素，回车打开图表、定位视图或在模型树中高亮
- **命令面板（Ctrl+Shift+P）**：搜索并执行主要菜单命令（含 15 种图表的新建命令、页签管理等）
- **页签管理**：Ctrl+Alt+PageUp / Ctrl+Alt+PageDown 切换图表；关闭当前 / 其他 / 全部图表
- **QuickEdit 快速编辑**：双击元素（或选中后按回车）弹出 StarUML 式就地编辑器——
  name / stereotype 字段，类元素带 attribute / operation 行内添加行，
  支持 `+name: type`、`name(p: type): ret` 速记语法，+ 按钮或回车即添加
- **模型树拖拽**：从模型资源管理器把任意模型元素拖到画布，即创建其视图
- 画布：网格点阵、双指滑动/滚轮平移（Shift 横向）、Ctrl/Cmd+滚轮或触控板捏合缩放、
  Alt/中键平移、框选、Shift 多选、8 向控制点缩放、方向键微移、右键菜单；
  **增量渲染**——拖动只更新受影响节点与相邻连线，平移/缩放不重建 SVG
- 建模：工具箱选工具 → 画布点击/拖拽创建；节点间拖拽连线（自动贴附边框、正交布线）；
  双击连线标签就地改名
- **连线路径编辑**：选中连线后，拖拽线段中点圆点插入拐点并移动、
  拖拽方形手柄移动已有拐点、**双击手柄删除拐点**；
  **连线名称标签可直接拖动**偏移（可撤销）
- 序列图：从生命线拖到生命线创建消息（箭头落在松开位置，可上下拖动调整时序）
- 编辑：Ctrl+Z / Ctrl+Y 撤销重做（命令栈）、Ctrl+X / Ctrl+C / Ctrl+V 剪切复制粘贴、
  Ctrl+D 创建副本、Del 从图表移除（连带其关联连线）、
  **Ctrl+Del 从模型删除并向所有图表级联清理视图与关联边**；
  属性面板支持成员上移/下移、**操作参数列表的增删与名称/类型编辑**；
  复制、剪切、粘贴、导出操作带右下角 Toast 提示
- 格式：对齐（左/水平居中/右/顶/垂直居中/底）、同尺寸（宽/高/宽高）、
  填充/线条/字体颜色、置于顶层/底层；连线路径支持**直角 / 斜线 / 圆角 / 曲线**，
  正交连线**自动避障**（无手动拐点时绕开其他节点，视图菜单/偏好可关），
  节点与连线可开**阴影**，每个元素可单独关闭**自动调整尺寸**
- 文件：新建 / 打开 / 保存 `.ouml`（JSON）、**防抖自动暂存**（配额不足时弹窗提示，
  并建议另存为文件）、**刷新后恢复打开的页签与当前图表**、
  导出 SVG / PNG / JPEG、**复制图表为图片**、**打印 / 导出 PDF**
  （Ctrl+P，打印对话框可选"另存为 PDF"）
- **模型校验（模型 → 验证模型…）**：检查同级重名、空名称、悬空模型引用、
  连线端点/容器引用与空图表；结果按错误/警告/提示分级，可一键定位到图表或模型树
- **偏好设置（Ctrl+,）**：网格大小（5/10/20px）、显示/吸附网格、浅/深主题、
  PNG/JPEG 缩放（1×/2×/3×）、透明背景（PNG/SVG）、自动调整类/枚举框尺寸、
  面板显隐；设置持久化并立即生效
- 视图：放大缩小、适应窗口、网格与吸附开关、**深色主题**（对标 StarUML Black，持久化）、
  **面板显隐**（侧栏 / 导航器 / 工具箱 / 工具栏 / 状态栏，持久化）

## 与 StarUML 的对应关系（来自 REA 分析）

| StarUML 7.1.1（逆向观察） | OpenUML（独立实现） |
| --- | --- |
| `src/static/index.html` 渲染端入口，main-view 布局模板 | `index.html` 相同的三栏布局 |
| 左侧 working-diagrams + toolbox，右侧 model-explorer + editors | 同布局与面板划分 |
| Backbone 风格 repository / command 引擎 | `repository.js` + `commands.js`（命令栈撤销/重做） |
| `extensions/essential/uml/toolbox/uml.json` 工具箱分组 | `metamodel.js#ToolboxGroups` |
| Canvas 2D 绘图引擎 | SVG 渲染（可无损导出 SVG） |
| UMLSequenceDiagram（生命线/消息） | `nodeviews.js` 生命线 + `edgeviews.js#renderMessage` |
| 状态机/活动图（状态、伪状态、控制流） | `nodeviews.js` 各伪状态渲染 + `renderSelfLoop` |
| Electron 壳 + IPC（`command` 通道等 43 个通道） | 纯浏览器运行，无需 IPC |

## 编辑器能力

- **项目模板**：文件 > 从模板新建（UML Minimal / Conventional / 4+1 View / Rational）
- **最近文件 / 直接写回**：File System Access API（Chromium），句柄持久化于
  IndexedDB，Ctrl+S 写回原文件；不支持的浏览器回退为文件选择器 + 下载
- **导出**：SVG / PNG / JPEG / **直接 PDF**（内置写入器，多页嵌入）/
  全部图表批量导出 / 复制到剪贴板 / 打印
- **选择联动**：在资源管理器中显示 / 在图表中定位
- **样式继承**：样式面板「继承到子视图」（可撤销）
- **Markdown 文档编辑器**：模型 > 文档编辑器（实时预览）
- 属性面板深化：isAbstract / isLeaf / isActive / isStatic / isReadOnly /
  isOrdered / isUnique（含对应渲染记法）

## 工程化

- **应用内 .mdj 导入**：文件 > 导入 StarUML 项目（`js/io/mdj.js`，与离线转换器同源逻辑）
- **.mfj 片段**：选中模型导出/导入（文件菜单）
- **代码生成**：模型 > 代码生成…（内置 Java 模板，`registerTemplate` 可扩展）
- **插件 API**：`window.openuml`（repository / 命令栈 / 工厂 / 命令面板注册）
- **国际化**：中文为源语言，偏好设置可切换 English（菜单 / 工具箱全部元素 /
  属性样式面板 / 对话框 / 校验面板 / 页签与面板标题，随项目持久化、可逆切换）
- **自动化测试**：`node --test tests/`（命令栈 / 仓库 / 序列化 / 校验 / 转换器 / 代码生成）
- **部署**：`.github/workflows/pages.yml`（push main 自动部署 GitHub Pages）
- **可访问性**：模型树 ARIA 树角色与键盘操作、图标按钮 aria-label、焦点样式

## 已知边界

- `.mdj` 支持应用内直接导入（文件菜单）；不支持的扩展区域、
  异常处理/中断边等会被跳过并在状态栏提示
- 复合结构图采用简化容器模型：部件/端口归属类、接口、组件或协作，端口自动贴边；
  协作使用绑定以 roleBindings 列表表达（角色 → 部件名）
- Timing 图：状态带 + 刻度 + 约束；时间类图元按生命线刻度间隔吸附，时间段可驱动
  状态值线，持续时间约束自动括住目标时间段
- 交互概览图的内联交互以缩略生命线示意，双击打开可编辑的完整序列图页签
- 拖动/平移/缩放采用增量更新（只改动受影响节点与连线，或仅更新视口变换）；
  增删元素和修改成员等结构性编辑仍会整图重建 SVG
- 暂不支持：活动图扩展区域/异常处理
